# Versión del programa

Esta distribución es Analizador de evidencias 1.4.0. Su repositorio se configura después de publicarla. Consulta `repositorio_url` en config.json o el remoto origin de esta raíz. Usa únicamente una URL verificada del repositorio de este programa.

Cuando haya repositorio, antes de cada envío consulta la revisión de su rama main con Git o las herramientas disponibles. En una copia limpia del repositorio correcto puedes actualizar por fast-forward. Si hay cambios locales, conserva esa copia y descarga otra en una carpeta nueva. Lee de nuevo AGENTS.md y la Skill de la revisión elegida. Mantén el código fijo durante el envío.

Mientras se use el ZIP inicial sin remoto configurado, comunica la versión distribuida y que la comprobación remota queda pendiente de configurar el repositorio. Puedes trabajar con esa distribución local autorizada. Si un remoto configurado falla, explica el error y consulta si se desea usar la copia disponible.

Configura repositorio_url con la URL real tras publicar el proyecto, o trabaja en un clon cuyo origin apunte a ese nuevo repositorio. Se publica el programa y sus plantillas vacías. Los datos de envíos se mantienen excluidos de Git.
